# Netflix Movies & TV Shows – EDA Project

Exploratory data analysis and an interactive Streamlit dashboard using the Netflix Movies and TV Shows dataset.

## Files
- `Netflix_EDA_Project.ipynb` — Google Colab/Jupyter EDA notebook
- `netflix_titles.csv` — dataset
- `app.py` — Streamlit dashboard
- `requirements.txt` — Python dependencies
- `.gitignore` — files excluded from Git

## Run the dashboard locally
Open a terminal in this folder and run:

```bash
pip install -r requirements.txt
streamlit run app.py
```

The dashboard expects `netflix_titles.csv` in the same folder as `app.py`.
